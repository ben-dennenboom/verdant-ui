# Verdant UI

A beautiful, self-contained UI component library for Laravel with Alpine.js and Tailwind CSS.

## Installation

You can install the package via composer:

```bash
composer require dennenboom/verdant-ui
```

## Documentation

See the [full documentation][1] for examples and detailed explanations of each component.

## Development

To start developing, you can start the development environment by running the following in your terminal:

```bash
composer run serve
```

To start developing, open `workbench/resources/views/playground.blade.php` and add your components in this file.

To view your components, simply visit `localhost:8000/playground`. You can also visit `localhost:8000/` to view documentation about the components.

[1]: https://verdant.dennenboom.be
